# Corpus real local

Cada caso guarda un `manifest.json` sin rutas de red.

- `r_2500kva_x30`, `r_2500kva_x29` y `r_1000kva` son snapshots geométricos
  reproducibles de hojas reales, disponibles para el runner.
- `r62174`, `r62135` y `r_giga` registran las fuentes objetivo que deben
  recapturarse cuando se restablezcan sus workspaces/DXF originales.

Los DXF y workspaces originales son locales y están ignorados por git.
